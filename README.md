# Cyber-Twin
Cyber Twin - your personal assistant for your everyday cybersecurity

## Loading the Chrome Extension

Follow these steps to install and run the Cyber Twin extension locally in Google Chrome:

1. **Open Extensions Management:**
   Open Google Chrome and navigate to `chrome://extensions/` in the address bar.
2. **Enable Developer Mode:**
   Toggle the **Developer mode** switch **ON** in the top-right corner of the page.
3. **Load the Extension Folder:**
   Click the **Load unpacked** button in the top-left corner and select the folder containing your `manifest.json` file (do not select the `backend` folder).
4. **Pin the Extension (Optional):**
   Click the **Extensions** (puzzle piece) icon next to your Chrome address bar and click the **Pin** icon next to **Cyber Twin** for quick access.
5. **Refresh Target Tabs:**
   Reload any open tabs (such as `x.com`) so the content script attaches to the active page.
